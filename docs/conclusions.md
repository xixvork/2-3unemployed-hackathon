# Conclusions

- Найбільший технічний виграш дав API-first підхід: він зменшив кількість переробок між фронтом і бекендом.
- Найбільший бізнес-ризик був у якості вхідних даних (CSV), тому валідація і прозорі помилки критично важливі.
- Фіксація припущень заздалегідь зняла більшість блокерів у задачах із неповною постановкою.
- Для наступного етапу пріоритет: закрити імплементацію endpoint-ів відповідно до зафіксованого контракту і додати інтеграційні тести.
